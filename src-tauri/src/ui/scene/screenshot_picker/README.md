`windows.patch` contains the original implementation of Windows version of screenshot picker detector mechanism, which, after testing, has proven to not work as intended due to the Snipping Tool popping open the overlay before letting other apps know that it did, and that it takes a snapshot of the desktop before doing so, so it's impossible to outrun the Snipping Tool...but just in case there's a solution somewhere in the unforeseeable future, the patch remains, for the attempt made at the time.
